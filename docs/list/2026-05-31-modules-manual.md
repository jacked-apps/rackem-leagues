Ed's decision: the module and system explainers read like an instruction
manual (what each is, what it does, what it contains, every dial). That's a
different thing from the glossary, which is a dictionary of quick definitions.

Covers: win-calculator, scoring-system, threshold-charts, points-system,
team-geometry, handicap-systems, handicap-mechanisms, match-format,
pairings-generator, tiebreak-system.

- Glossary entries for these stay short ("what it is" plus a link out). Ed
  writes the full manual content later.
- The glossary is a flat A to Z list today, with no sections. A "Modules"
  section or tab needs a `category` field on entries plus grouped rendering.
  The other route is a dedicated Modules page on the Learn hub.
- Naming lean: "Modules" over "Module Systems."
